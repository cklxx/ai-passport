配置自己的飞书应用

刷机前先准备：
1. 打开飞书开放平台创建企业自建应用；
2. 申请 im:chat、im:message、im:message.send_as_user、speech_to_text:speech、offline_access；
3. 发布应用并确保自己的账号在可用范围；
4. 从“凭证与基础信息”复制 App ID 和 App Secret。

请先完成通用固件刷入，并让设备停留在“配置私人飞书”页面。凭据只通过当前浏览器与 USB 串口发送，不会上传服务器或写入固件文件。

推荐直接用手机扫描设备二维码，进入设备自己的本地配置页；下面的 USB 表单只作为备用。

仅在可信电脑上操作。完成后请从飞书后台继续扫描设备显示的授权二维码。
